# MO-RIS (MOBILE ROAD INSPECTION SYSTEM)

## Tentang

MO-RIS (Mobile Road Inspection System) merupakan sistem pemetaan jalan berlubang berbasis web yang menampilkan lokasi pothole pada peta secara interaktif. Sistem ini bertujuan membantu masyarakat mengetahui kondisi jalan sekaligus mempermudah petugas/operator dalam mengelola data hasil deteksi.

PODCAST memiliki dua jenis pengguna:

- Operator → Mengelola data pothole.
- User Umum → Melihat kondisi jalan melalui peta.

---

## Fitur Utama

### Operator

- Login
- Dashboard
- Melihat seluruh data pothole
- Menambah data pothole
- Mengubah data pothole
- Menghapus data pothole
- Mengubah status perbaikan
- Melihat statistik

### User

- Melihat peta interaktif
- Melihat posisi saat ini
- Mencari lokasi
- Melihat detail pothole
- Filter berdasarkan kondisi
- Melihat status perbaikan jalan
